# Kay’s Lumière Frontend

Luxury fine jewelry website built with semantic HTML, CSS, and JavaScript.

## Structure
- `index.html` — Home
- `about.html` — Brand story and values
- `shop.html` — Product grid with filters and quick view
- `product.html` — Product detail page
- `collections.html` — Editorial collections
- `contact.html` — Contact form and map
- `locations.html` — Delivery coverage
- `cart.html` — Frontend cart
- `checkout.html` — Luxury checkout UI
- `assets/css/style.css` — Global styles
- `assets/js/main.js` — Interactions and cart logic
- `assets/images` — Logo and product imagery

## Features
- Luxury editorial layout with refined typography
- Smooth scroll, fade-in sections, hover zoom, and micro-animations
- Filterable shop with quick view modal
- LocalStorage cart with quantity controls
- Fully responsive, SEO-friendly markup
